# Banco

Titulo: The bank of the TwinTowers

Neste projeto, utilizaremos o conceito de herança, composto por uma classe pai (superclasse) e duas classes filhas (subclasses). O objetivo do trabalho é aplicar a herança na prática através do desenvolvimento de um simulador bancário.
